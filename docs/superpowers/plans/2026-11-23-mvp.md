# Settings Suggestor MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live, mobile-first static web app where a user enters (or defaults) their gear, picks a scenario, and gets an achievable aperture/shutter/ISO suggestion with a plain-language explanation. No photos involved.

**Architecture:** Vite SPA. Pure engine in `src/engine/` (no UI imports) takes `GearProfile` + `Scenario` and returns `Suggestion`. `src/storage/` persists the gear profile in IndexedDB via `idb`. Components in `src/components/` are thin.

**Tech Stack:** Vite, React, TypeScript (strict), Tailwind v4 (`@tailwindcss/vite`), `idb`, Vitest + Testing Library + `fake-indexeddb`, ESLint, Prettier, `@fontsource-variable/geist`, `@fontsource-variable/bricolage-grotesque`. Deploy: Vercel (static).

**Spec:** `docs/superpowers/specs/2026-11-23-settings-suggestor-design.md`

## Global Constraints

- Fully client-side; no network calls except loading the app itself. Fonts self-hosted.
- Engine files in `src/engine/` import nothing from React, DOM or `src/components`.
- TypeScript strict, no `any`, named exports, small components.
- Never suggest settings outside the gear's limits.
- Every suggestion has a one- or two-sentence explanation; impossible exposures are clamped and flagged in `warnings`.
- Light default theme, dark follows system. Tokens: page `#ECE6D8`, card `#F7F2E6`, text `#1F1B14`, button `#26201A` on `#FAF6EC`, input fill `rgba(61,48,25,.07)` with 1px ring `rgba(61,48,25,.13)`, 12px radii. Dark: bg `#0E0E0D`, surface `#1B1B19`, fg `#EDEDEA`, muted `#A09F98`, accent `#B9A47A`, danger `#F19A92`. Headings Bricolage Grotesque 600, body Geist.
- Mobile-first, keyboard-usable.
- `samples/` is gitignored. Never commit personal photos.
- Run `npm test` and `npm run lint` before every commit; commit after each working step (owner's spec). Local commits only: pushing waits for the owner's "push" (to `main`).
- Default branch is `main`.

## Review Focus

1. Focal length outside the lens range: clamp to range and warn (tested in Task 7).
2. Prime lens (wide and tele max aperture equal) and zoom lens (f/3.5-5.6) both resolve the right max aperture (Task 3).
3. Scene too dark for the gear (night, slow lens, low ISO ceiling): result stays inside limits, warning present (Task 7).
4. Scene too bright (sun, wide-open goal, shutter ceiling 1/4000): stop down or raise nothing illegal, still in limits (Task 7).
5. Corrupt or missing stored profile in IndexedDB: fall back to defaults, no crash (Task 4).

### Task 7: Suggestion engine

**Files:** Create `src/engine/suggest.ts`, `src/engine/suggest.test.ts`, `src/engine/explain.ts`.

**Interfaces:** Consumes everything from Tasks 3 and 6. Produces `suggest(gear: GearProfile, scenario: Scenario): Suggestion`.

**Algorithm (decided here):**
1. Clamp focal with `clampFocal`; add a warning if it changed.
2. Required shutter: the faster of `reciprocalShutter` and the subject floor (action and wildlife 1/1000, street 1/250, portrait 1/125, macro 1/250, landscape and night-sky none). `freeze-motion` goal makes it at least 1/1000.
3. Target aperture: `blur-background` goal uses the widest (`apertureMaxAt`); landscape and balanced goal use f/8 (clamped into the gear's range); other cases use f/5.6; `freeze-motion` uses the widest. Mode: shutter-priority for `freeze-motion` and action or wildlife subjects, otherwise aperture-priority.
4. Start at `isoMin`. Compute shutter with `shutterFor`. If slower than required: raise ISO in one-third steps up to `isoMax`; if still too slow, open aperture up to the widest; if still too slow, keep the slowest achievable, add a warning naming the consequence (blur or noise).
5. If faster than `shutterFastestS`: stop the aperture down toward `apertureMin`; if still too fast, set the shutter to `shutterFastestS` and warn "scene is very bright, consider an ND filter".
6. Clamp the shutter to `[shutterFastestS, shutterSlowestS]`, snap values, build the explanation in `explain.ts` (plain language, one or two sentences, naming the goal and the main trade-off).

- [ ] **Step 1: Write failing tests:** `bright sun, balanced, 50mm gives about f/8, ISO 100, around 1/250 on default gear`; `action in overcast gives shutter at least 1/1000 and ISO above 100`; `blur-background uses the widest aperture at the given focal length`; `night with the default kit lens stays inside the gear limits and includes a warning`; `very bright scene with a wide-open goal never exceeds the fastest shutter and warns`; `focal length outside the lens range is clamped and warned`; `a prime lens (50mm f/1.8) suggests f/1.8 for blur-background`; `every result's aperture, shutter and ISO are inside the gear limits` (loop over all subjects x lights x goals on three gear profiles); `explanation is non-empty and at most two sentences`.
